FAQ

HÄUFIGE FRAGEN.

Brauche ich Minecraft bereits?

Ja. Du benötigst eine gültige Minecraft-Java-Edition-Lizenz. Der LeipzigCraft-Launcher ersetzt keine Minecraft-Lizenz.

Muss ich Mods selbst installieren?

Nein. Der Launcher ist dafür gedacht, das benötigte Modpack und spätere Updates automatisch bereitzustellen.

Was kostet LeipzigCraft?

Der Download und das Spielen auf dem Server sind aktuell kostenlos.

Warum warnt Windows eventuell beim Download?

Bei neuen oder nicht signierten Windows-Anwendungen kann Microsoft Defender SmartScreen eine Warnung anzeigen. Für eine öffentliche Veröffentlichung ist Code Signing empfehlenswert.
